# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Safeherd, please report it
**privately** rather than opening a public issue.

**Email:** safeherd@example.com

We will acknowledge receipt within 48 hours and aim to provide a fix or
mitigation within 7 days for critical issues.

## Scope

This policy covers the Safeherd backend API, the contracts package, and
the facility/capacity management modules. Frontend-only cosmetic issues
(e.g., CSS rendering) are not security vulnerabilities.

## Supported Versions

Only the latest version on the `main` branch receives security updates.
